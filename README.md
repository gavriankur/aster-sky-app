# Aster

Aster is a mobile-first interactive astronomy frontend inspired by the experience of pointing a phone at the night sky. It is an original interface and does not reuse SkyView branding or assets.

## Features

- Animated star field and interactive celestial objects
- Object search and detail cards
- Night-vision display mode
- Device-orientation tracking on supported phones
- Responsive, safe-area-aware interface
- Installable web app manifest

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run build
```

Phone orientation requires HTTPS and explicit sensor permission on supported mobile browsers.
